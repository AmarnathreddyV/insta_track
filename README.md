# Creator Registration

Next.js creator registration UI for the Influencer Analytics Platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current scope

This package contains the public creator registration UI. The Meta button is currently a demo action. The next step is to connect it to the existing Facebook Login for Business OAuth flow and PostgreSQL backend.

Keep Meta App Secret and database credentials server-side.
